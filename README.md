
# Tarea

La tarea de la materia de Desarrollo Mobil


## Compilar y ejecutar

Clona el proyecto (Necesitas git o descargar este repo como zip)

```bash
  git clone https://github.com/Gonanf/guagnano
```

Ve al directorio

```bash
  cd guagnano
```

Compila (Necesitas CMake)

```bash
  cmake -B build
  cmake --build build
```

Ejecuta

```bash
  ./build/tarea
```


## Appendix

Esta tarea tiene una manera distinta (pero equivocada) para eliminar registros, que viene de un reto.
